---
name: Private onboarding policy
description: Public factory signup is authorized; staff invitations and release verification remain separate.
---

Allow public self-service registration of a unique, new factory with a Tenant ID,
Factory Name and Master Password. Existing demo data must never become a new
factory's records. Creating a factory must not grant access to any existing factory.

**Why:** The user's premium-upgrade brief explicitly replaces invitation-only
factory onboarding with instant registration. The user confirmed that this
upgrade remains in the React app.

**How to apply:** Keep staff invitation and role safeguards; public signup only
creates a brand-new tenant and its owner. Preserve the existing encryption root;
password management is not permission to rotate the vault key. Do not equate
passing development tests with a security sign-off or disaster-recovery validation.
